# INcrein 新Webサイト（STUDIO）制作

株式会社INcrein の法人向け新Webサイトを STUDIO で制作するための、原稿・設計・チェックリスト置き場です。

- サイト本体：STUDIO
- 管理表（正本）：[INcrein_Web制作 スプレッドシート](https://docs.google.com/spreadsheets/d/1AuPMYPdZS7N7nLL8cPuKsHWV_ykzXHNXoKQn-tV43lk/edit)
- AI向けルール：[AGENTS.md](AGENTS.md)（Codex・Claude 共通）

## 使い方

1. AI（Codex／Claude）が `docs/copy/` の原稿を作成・修正し、プルリクエストを出す
2. もう一方のAIがルール違反・抜けをレビューする
3. 代表が内容を確認してマージ
4. マージした原稿を STUDIO に反映
5. 公開・ドメイン切替は代表が判断して実行
