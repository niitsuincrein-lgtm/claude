# 施工事例（CMS設計）

- 状態：設計（期限：CMS作成 2026/10/30、5件掲載 2026/11/09、10件 2026/12/14）
- URL案：/works（一覧）、/works/[slug]（詳細）
- 見出し（H1）：施工事例
