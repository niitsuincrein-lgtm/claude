# Codex タスク 001：テンプレートの残りを INcrein 用に書き換える原稿を作る

- 依頼者：代表（Claude 経由で作成）
- 作成日：2026-10-26
- 担当：Codex
- レビュー：Claude
- 前提：作業前に `AGENTS.md` を読むこと。特に第4章（文章ルール）と第5章（承認が必要なこと）

## 背景

STUDIO の仮公開サイト（https://purple613025.studio.site）はテンプレートの文言が残っている。詳細は `docs/studio-status.md`。
このリポジトリから STUDIO は直接編集できないので、**STUDIO にそのまま貼り付けられる差し替え原稿**を作るのが今回の作業。STUDIO への反映と公開は代表が承認してから別途行う。

## 作るもの

新規ファイル `docs/copy/studio-fixes.md` を作り、次の5つを「場所 → 現在の文言 → 差し替える文言」の形でまとめる。

### 1. SEO タイトルと説明文（3ページ分）
- 対象：`/`、`/info`、`/privacy-policy`
- `/` は `docs/seo.md` の TOP のタイトル案・説明文案をもとにする
- `/info`：「お知らせ｜株式会社INcrein」と説明文
- `/privacy-policy`：「プライバシーポリシー｜株式会社INcrein」と説明文
- タイトルは全角32文字前後、説明文は120文字前後

### 2. フッター表記
- 「© 2026 THE COMPANY」を INcrein の表記に

### 3. よくある質問（TOP の #faq セクション）
- `docs/copy/faq.md` の「共通（TOP）」5問を使う
- 回答に `【要確認】` が残っている質問は、**確定している部分だけで回答を書く**か、掲載を見送る。推測で埋めない
- 対応エリアの表記は `docs/open-questions.md` Q12 が未回答なので、両方の案を併記して代表に選んでもらう

### 4. プライバシーポリシー本文
- 現在の本文はダミー（「◯◯株式会社」「XXX-XXXX-XXXX」「info@example.co.jp」）
- 会社情報は `docs/copy/company.md` と `docs/studio-status.md` の確定値だけを使う
- 問い合わせフォームで取得する項目（お名前・会社名・メールアドレス・電話番号・お問い合わせ内容）に合わせた利用目的にする
- 電話番号・メールアドレス・制定日は `【要確認】` のまま残す
- 法律の専門家の確認が必要な点があれば、本文の外に注記する

### 5. お知らせ
- 「準備中です」の代わりに、公開時に載せるお知らせ1件の案（タイトル＋本文100文字程度）

## 守ること

- AGENTS.md 第4章の文章ルールに違反しない（No.1・緊急性表現・誇張なし）
- 確定していない数字や事実を作らない。分からない値は `【要確認：〜】`
- STUDIO の公開・設定変更はしない（そもそもこのタスクの範囲外）
