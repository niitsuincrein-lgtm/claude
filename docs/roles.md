# 役割分担（2026-10-27 決定）

現状の制約をふまえた分担。
- ChatGPT の Work モードは 1 回 15〜20 分で数時間止まる（課金しない方針）
- Claude が STUDIO を操作できるのは代表の PC がついている間だけ。CMS の画像差し替えは Claude の操作では保存できなかった
- GitHub は誰でも PC なしで読み書きできる

| 担当 | やること | やらないこと |
|---|---|---|
| **代表** | 決定（料金・表記・公開日など）、公開ボタン、フォーム送信テスト、プラン・支払い、ログインが必要な初回操作 | 細かい STUDIO 作業（AI に任せる） |
| **ChatGPT（Work）** | STUDIO の操作全般（ページ作成・レイアウト・CMS 記事と画像・alt）、画像生成、クラウドブラウザでのプレビュー確認、進捗を `docs/studio-progress.md` に記録 | 公開、課金、新しい CMS モデル、文章ルール外の表現 |
| **Claude** | 原稿・指示書づくり（ChatGPT の作業を 1 回で終わる単位にまとめる）、ルール点検とレビュー、GitHub 管理、スケジュール管理（上限回復後の再開）、PC がついているときの下書き点検・テキスト修正・SEO 設定 | 画像生成、CMS 画像の差し替え、公開 |
| **Codex** | リポジトリ内の原稿の点検（第4章ルール）、原稿間の表記ゆれチェック | STUDIO 操作 |

## 進め方
1. Claude が指示書を `docs/chatgpt-tasks/` に作る（1 回の Work で終わる量に分ける）
2. ChatGPT が STUDIO で作業し、区切りごとに `docs/studio-progress.md` に記録
3. Claude が GitHub の記録と STUDIO 下書き（PC がついているとき）を点検し、問題があれば次の指示書に入れる
4. 代表が決定事項に回答し、最後に公開ボタンを押す
