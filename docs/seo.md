## 共通設定チェック

- [ ] 全ページのタイトル・説明文を STUDIO の「ページ設定 > SEO」に入力
- [ ] 見出しは H1 を1ページ1つ。H2/H3 の順序を守る
- [ ] 画像の alt にテキストで内容を書く（例：「1K空室 キッチン清掃後」）
- [ ] 内部リンク：サービスページ ⇄ 施工事例 ⇄ お問い合わせ
- [ ] OGP画像の設定
- [ ] XMLサイトマップ（STUDIOで自動生成）を Search Console に送信
- [ ] GA4 の測定ID を STUDIO に設定
- [ ] Googleビジネスプロフィールのサイト URL を新サイトに更新
- [ ] 旧サイトURLの一覧を作り、301転送先を決める（**切替は代表のみ**）

上記の「計測系」は、実際に画面で確認できるまで完了扱いにしない。
