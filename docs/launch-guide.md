# 公開と公開後の手順（Claude 作成 2026-10-27）

## 1. 公開前に代表がやること（各5分以内）

1. **問い合わせフォームの送信テスト**：プレビューでフォームを送信し、通知メールが届くか確認（迷惑メールも）
2. ~~送信完了ページの文言確認~~ → 「2営業日以内に折り返し連絡」で確定（2026-10-27）
3. **プライバシーポリシーの制定日**を入れる（公開日でよい）
4. STUDIO 右上の「公開」を押す

## 2. 独自ドメイン（increin.co.jp）について

- STUDIO で独自ドメインを使うには有料プランが必要。**課金しない方針のため、当面は STUDIO の URL（purple613025.studio.site）で公開**する形になる
- 独自ドメインに切り替えるときは、代表が有料プランを判断してから。切替時に旧サイトの URL を新しい URL に転送（301）する

### 旧サイト → 新サイトの転送表（切替時に使う）

| 旧 URL（increin.co.jp） | 新 URL |
|---|---|
| /index.html | / |
| /content1.html（エアコンクリーニング） | /fresh |
| /content2.html（空室クリーニング・原状回復） | /white |
| /content3.html（ご依頼について） | /#flow（トップの流れ） |
| /content4.html（会社案内） | /#company（トップの会社情報） |
| /wp/（新着情報） | /info |
| /contact.html | /#contact |

## 3. 公開後すぐ（代表、Claude が手順を案内）

1. **Google Search Console**：サイトを登録し、`/sitemap.xml` を送信。STUDIO のダッシュボード「Search Consoleを設定」から進める
2. **Google ビジネスプロフィール**：ウェブサイト欄を新しい URL に変更
3. **計測**：問い合わせ→見積→受注を統合管理表に記録（経路欄に「HP」）
