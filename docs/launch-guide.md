## 2. 独自ドメイン（increin.co.jp）について

- **方針（2026-10-28 代表決定）**：サイト完成後に STUDIO の有料プランへ移行し、独自ドメインで公開する
- **順番が大事**：STUDIO の URL（purple613025.studio.site）のまま先に公開すると、旧サイトと同じ文章が2か所に出て検索評価が割れる。完成までは「公開」を押さずプレビューで確認し、**有料プラン移行 → 独自ドメイン接続 → 公開 → 旧URLの301転送**を同じ日にまとめて行う
- 旧サイト（韋駄天）の契約は、新サイトが独自ドメインで表示され、転送とメールが問題なく動くのを確認してから解約する。increin.co.jp でメールを受けている場合は、ドメイン切替でメールが止まらないよう事前に確認する
- ドメインの管理会社（どこで increin.co.jp を取得・更新しているか）を確認しておく。STUDIO 側で表示される DNS 設定値を、その管理画面に入れる作業が必要
