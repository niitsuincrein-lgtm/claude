# 公開と公開後の手順（Claude 作成 2026-10-27）

## 1. 公開前に代表がやること（各5分以内）

1. **問い合わせフォームの送信テスト**：プレビューでフォームを送信し、通知メールが届くか確認（迷惑メールも）
2. ~~送信完了ページの文言確認~~ → 「2営業日以内に折り返し連絡」で確定（2026-10-27）
3. **プライバシーポリシーの制定日**を入れる（公開日でよい）
4. 有料プラン移行と新ドメイン接続（第2章）を済ませてから、STUDIO 右上の「公開」を押す

## 2. ドメインについて（2026-10-28 代表決定）

- increin.co.jp は韋駄天の管理で切替が面倒なため、**新しいドメインを取得して新サイトに使う**。STUDIO は完成後に有料プランへ移行して接続する
- ドメイン名の候補：increin.jp（日本の会社向けで信頼感がある）、increin.com。.co.jp は1社1つまでなので、increin.co.jp がある限り別の .co.jp は取れない
- **順番**：完成まではプレビューで確認だけ → 有料プラン移行 → 新ドメイン取得・接続 → 公開。studio.site のままでは公開しない

### 旧サイト（increin.co.jp）の片付け

- 新旧に同じ文章があると検索評価が割れるので、新サイト公開後は**旧サイトをなるべく早く閉じる**
- できれば韋駄天に「旧サイトの各ページから新ドメインへの301転送」ができるか確認する。できれば検索の評価を引き継げる（対応表は下）。できなければ、旧サイトのトップに「サイトを移転しました」と新アドレスへのリンクを置いてから解約
- 解約するとき、increin.co.jp のドメインを手放すかも決める。手放すと第三者に取られる可能性がある。名刺・チラシ・請求書などに旧アドレスが残っていれば差し替える
- Googleビジネスプロフィールのウェブサイト欄、各種ポータルや取引先に登録しているURLを新ドメインに変更

## 3. 公開後すぐ（代表、Claude が手順を案内）

1. **Google Search Console**：サイトを登録し、`/sitemap.xml` を送信。STUDIO のダッシュボード「Search Consoleを設定」から進める
2. **Google ビジネスプロフィール**：ウェブサイト欄を新しい URL に変更
3. **計測**：問い合わせ→見積→受注を統合管理表に記録（経路欄に「HP」）

## 4. 公開後に順次（AI で進められる）

- 施工事例：CMS が無料枠の上限（3）なので、当面は「お知らせ」に事例記事として掲載（代表が写真と掲載許可を用意）
- 料金表・納期・保証：代表が決めたら原稿化して掲載
